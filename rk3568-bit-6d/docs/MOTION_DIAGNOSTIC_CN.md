# 标记慢速旋转诊断实验

本轮只验证20 mm、ID42标记的位姿，批头未固定，不能作为批头6D识别结果。

- 原始数据：开发板 /userdata/6D-native/part/data/marker_diagnostic_20261026_030111；959张1280×720未叠字PGM和逐帧JSONL保留。
- 标记解码959/959；有效位姿958/959（99.90%）。包含等待与静止时间，不代表纯运动检测准确率。
- 第583帧被位姿质量门限拒绝，未用旧位姿补齐，门限未放宽。
- 第188→189帧旋转变化10.261°，第189→190帧11.014°；出现单帧偏离并返回，仍需排查平面PnP多解和角点噪声，不能判定高精度通过。
- 相对首帧最大姿态变化34.132°，结束相对首帧5.806°。这是算法估计值，没有独立角度真值。
- 板端诊断录制9.218帧/秒，处理耗时中位数80.06 ms，图像保存中位数18.216 ms；采集序列跳过1318帧，不是1318次标记检测失败。
- Ubuntu对相同56张抽样图以INTER_AREA缩放，640/960/1280均解码56/56。只比较解码，没有证明各分辨率位姿精度相同；Ubuntu CPU时间不能代表板端RGA性能。该抽样不含第189帧。
- 原始输入为板端RGA缩放后的1280图，不是4K原图；无法完全复现原图角点精修。
- 正常640×360标记预览已自动恢复，持续录制已停止。

后续优先：用可复现数据比较平面PnP候选解及单帧异常判据，分别报告原始位姿和处理后位姿；禁止仅用平滑隐藏错误。批头业务验证需先将批头与标记牢固固定，并实测二者刚性变换。
