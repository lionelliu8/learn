不带`--assembly`，日志不输出`object_pose`。不把标记位姿当作批头位姿。

## 复现

```sh
cd /userdata/6D-native/part
python3 analyze_marker.py data/marker_only_response_20261026_v01/baseline01.jsonl
python3 analyze_marker.py data/marker_only_response_20261026_v01/approach01.jsonl \
  --reference data/marker_only_response_20261026_v01/baseline01.jsonl
python3 summarize_marker_session.py data/marker_only_response_20261026_v01 \
  --output results/marker_response_20261026_new
```

分析器使用实际观测旋转中的medoid，不直接平均旋转向量，避免±π分支导致误统计。
估计的位姿是标记坐标到相机光学坐标的变换：X右、Y下、Z前，位置单位米。
平面标记两解与标定误差仍需关注；响应测试不能代替这些问题的精度验证。

本轮结束后已关闭连续录制，保留原始日志和阶段片段，同时保持MIPI实时预览。
后续优先保存同步预览、只做单一慢动作对照，区分可见性/模糊与检测失败；
然后比较960或1280宽检测图的成功率与处理耗时，再决定是否调整分辨率或曝光。
单个方形标记的姿态歧义仍需质量检查，不用平滑掩盖错误解。
恢复批头测试需要先把标记与批头真正固定，再核对安装偏移。
